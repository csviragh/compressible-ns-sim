About the model
∂ρ/∂t + ∇·(ρu) = 0
∂(ρu)/∂t + ∇·(ρu⊗u + pI − σ) = f

σ = μ(∇u + ∇uᵀ) + λ(∇·u)I. In 2D σ = 2μ(D − ½tr D·I) + ζ(∇·u)I with bulk viscosity ζ = λ + μ, so ζ ≥ 0 requires λ ≥ −μ (Stokes: λ = −μ). Sound waves damp at (2μ + λ)k²/(2ρ), shear waves at μk²/ρ. Finite volume on the periodic unit square: MUSCL–minmod + Rusanov flux, centred viscous fluxes, SSP-RK3, CFL-adaptive Δt.
