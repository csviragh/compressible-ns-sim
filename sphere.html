Rotation (Coriolis)

a = −2Ω (ẑ·n) n × u, f = 2Ω cos(colatitude)

Lamé viscosity

μ(Δ_B u + K u) + (λ+μ)∇(∇·u), K = 1

Self-propulsion

Pairwise repulsion (retarded)

f = A Σy [ρ(y, t − d/vint) − ρ(x,t)] K(d) êy→x dAy, d = great-circle distance

K(d) = [(R0/d)α − 1](1 − d/R0)², own cell excluded. The −ρ(x,t) term removes the (grid-induced) response to a uniform density, which is zero in the continuum, so uniform ρ gives exactly zero force on the non-uniform cubed-sphere grid. Only the repulsion is retarded. 2D Coulomb mode is not available on the sphere yet. Without repulsion there is no pressure, so self-propulsion collapses the mass into near-singular sheets within seconds and those sheets lock onto grid lines (panel edges); keep A ≳ 50 for a resolved, grid-independent flow.

Order parameters

Global polar order ⟨û⟩ is undefined on a sphere (each cell has its own tangent plane; hairy-ball theorem). Shown instead: ⟨cos⟩ = mean alignment of edge-neighbour pairs with uj parallel-transported to xi, and ⟨cos⟩ρ the same weighted by pair mass; Lz = Σm(x×u)·ẑ / Σm|u|sinθ (+1 = all eastward, −1 = all westward); ΦL = |Σ m x×û| / Σm (1 = all mass on parallel great circles about one axis).

About the model

Equiangular cubed-sphere finite-volume grid. Velocity stored as 3D Cartesian vectors, projected to the tangent plane after each sub-step. Semi-Lagrangian advection along great circles with parallel transport; conservative upwind density fluxes; Coriolis applied as an exact rotation of u about the local normal (does no work). Centrifugal force is absorbed into the geopotential (not modelled). Time in s, lengths in R.
